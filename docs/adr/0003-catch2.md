# 3. Use Catch2 as Unit Testing Framework

## Context
Developing a reliable raytracer requires automated unit tests and test-driven development (TDD). We considered alternatives such as GoogleTest, Doctest, Boost.Test, or writing custom assertion macros and test runners from scratch.

## Decision
We will use Catch2 (version 3) to write automated tests. Catch2 is a C++ library used to write tests, which we integrate directly into the CMake build via `FetchContent`.

## Status
Proposed

## Consequences
Tests are written with clear, expressive C++ assertions and structured sections without requiring manual external library installations on contributor machines.
However, compiling Catch2 alongside the project increases initial build times, and fetching it during CMake configuration requires network access.
