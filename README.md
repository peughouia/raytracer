# raytracer
Une équipe développe un outil de rendu (ray tracer) pour un studio qui produit des films d’animation pour enfants. Les designers ont déjà storyboardé et modélisé les scènes en 3D (à base de triangles) ; il reste à les rendre. notre rôle est de comprendre le besoin réel et résoudre les potentiels problèmes
